## 🚀 About the project

Welcome to the repository of **Stargate: Chronicles**!
This project, born from a passion for the Stargate universe, has a dual purpose:

1. **Create a free game (Management / Narrative RPG) for the community**.
2. **Keep my technical watch up to date** (in my free time)

**Target gameplay:**
**Stargate: Chronicles** puts you in command of the SGC. The gameplay is a mix of:

- **Strategic Management (50%)**: Base development (construction, staffing, technology research, political relations).
- **Narrative RPG (50%)**: Narrative exploration of the universe and character development.

The idea is to have a solid game foundation, extensible by the community, with a content management module allowing the
community to contribute to the richness of the game.

👉 **Please consult the Game Design Document [IDEE.md](./IDEE.md) for the full vision.**
