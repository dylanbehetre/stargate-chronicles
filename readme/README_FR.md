## 🚀 À propos du projet

Bienvenue sur le repository de **Stargate : Chronicles** !
Ce projet, né d'une passion pour l'univers de la Porte des Étoiles, a un double objectif :

1. **Créer un jeu (Gestion / RPG Narratif)** gratuit **pour la communauté**.
2. **Faire ma veille technique** (sur mon temps libre)

**Le Gameplay cible :**
**Stargate : Chronicles** vous met aux commandes du SGC. Le gameplay est un mélange de :

- **Gestion Stratégique (50%)** : Développement de la base (construction, effectif, recherche technologique, relations
  politiques).
- **RPG narratif (50%)** : Exploration narrative de l'univers et développement des personnages.

L'idée est d'avoir un socle de jeu solide, extensible par la communauté avec un module de gestion du contenu
permettant à la communauté de contribuer à la richesse du jeu.

👉 **Veuillez consulter le Game Design Document [IDEE.md](./IDEE.md) pour la vision complète.**
