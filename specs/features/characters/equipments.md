# Equipments

## Find Rating

Each equipment has a Find Rating which is used to determine how easy
it is to find the equipment in the game.

The Find Rating is decreased by 1 for Characters having the related race.

To find an equipment, the character must do a Touch (skill) Test higher
than the Find Rating multiplied by 4.

## Equipment Type

There are 3 types of equipment in the game: Weapon, Armor, and Miscellaneous.

### Weapon

Weapons are équipements used to attack enemies.
Each weapon has :
- a type : gun, rifle, energy weapon, melee weapon, etc ;
- a damage computation rule : used to determine how much damage the weapon does when it hits an enemy ;
- a stunt computation rule (optional)
- an access restriction (optional)
- a find rating
- a description

### Armor

Armors are équipements used to protect the character from damage.
Each armor has :
- a type : physical or energy ;
- a protection computation rule : used to determine how much damage the armor absorbs when the character is hit by an enemy ;
- an access restriction (optional)
- a find rating
- a description

### Medical Equipment

Medical equipments are used to heal the character or provide other medical benefits or effects.
Each medical equipment has :
- a healing computation rule : used to determine how much health the equipment restores when used ;
- a find rating
- a description

### Miscellaneous

Miscellaneous equipments are others object which can enable some game options or provide some benefits or effects.
