# Features

Functional/business specifications for **Stargate: Chronicles**, organized **one folder per business domain**,
with **one `.md` file per feature**. Related features are cross-linked directly between their `.md` files instead
of duplicating content.

See [`dev-guide/documentation-workflow.md`](../dev-guide/documentation-workflow.md) for the full rules on how to
add or update a feature spec.

## Domains

### [`characters/`](./characters) — Character creation & RPG rules

Rules governing playable characters, adapted from the *Stargate Coalition* tabletop RPG ruleset.

- [Characters](./characters/characters.md) — entry point: creation process, experience points, characteristics.
- [Races](./characters/races.md) — playable races and their adjustments.
- [Skills](./characters/skills.md) — skills tied to characteristics and how they improve.
- [Equipment](./characters/equipments.md) — weapons, armor, and equipment rules at character creation.
